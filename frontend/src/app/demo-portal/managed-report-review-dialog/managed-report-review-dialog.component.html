參數名稱與資料型別
由上傳的 RPT 讀取，用來辨識該報表參數，不能在此修改。
顯示名稱
使用者在執行報表時看到的欄位名稱，可依業務語意調整。
值來源
選擇使用者輸入、SQL 清單（LOV）或目前登入使用者。選 SQL LOV 時，請填寫查詢與回傳欄位。
預設值
使用者未修改時帶入的值；多選值請以逗號分隔。
必填
啟用後，未提供值就不能產生報表。
前台顯示
勾選時，參數會出現在使用者執行報表的條件區，讓使用者查看或修改；取消勾選時會隱藏，系統改用預設值或系統帶入值。
SQL LOV 欄位
SQL 僅能是單一 SELECT。值欄位是實際傳給 RPT 的欄名；顯示欄位是提供使用者閱讀的欄名。
