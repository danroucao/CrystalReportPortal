1. 識別與自動匹配

此區皆需由管理者設定。系統會以「匹配用參數名稱」搭配資料型別、多值與範圍能力比對上傳的 RPT 參數；代碼僅供管理與辨識。

2. 輸入方式與值來源

新增時系統預設為 String／Text／使用者輸入；選擇目前使用者或勾選允許多值時，系統會自動調整輸入元件，其餘選項由管理者決定。

3. SQL 清單設定

常用參數模板不綁定特定 RPT，因此此區需由管理者依實際資料庫填寫。上傳後的報表參數設定頁則會讀取 RPT 參數名稱 @ 後的 SELECT 作為預填草稿。查詢結果需包含值欄位與顯示欄位，且僅允許讀取用的單一 SELECT 查詢。

系統預設或自動調整

新增時的初始值
預設為 String、Text、使用者輸入、必填且顯示於執行頁；多值與範圍預設關閉。這些值可修改。
輸入元件
選擇「目前使用者」時，系統改為 Hidden 並隱藏欄位；勾選「允許多值」時，系統改為 MultiSelect。
既有模板的欄位值
編輯時顯示的是上次儲存的模板設定，不會重新依 RPT 或 SQL 自動覆寫。
RPT SQL 預填規則
在上傳後的「設定報表參數」頁，若 RPT 參數名稱為 CT@select ...，系統會讀取 @ 後的 SELECT 並預填 SQL；常用參數模板頁不綁定 RPT，無法預先判定該 SQL。
自動套用依據
上傳 RPT 時，系統以匹配名稱、資料型別、多值與範圍能力比對；符合且唯一的已啟用模板才會套用。
